Privacy and terms

Last updated 20 October 2026

SmashTrack runs badminton, table tennis and squash sessions. It has no accounts, no server of its own and no tracking. This page says exactly what it keeps and where that stays.

What SmashTrack stores

Only what you type or choose while using it:

  • the names of the players you add
  • courts, rounds, scores, match history and standings
  • your settings: theme, accent colour, sound and keyboard shortcuts

Where it is stored

In your own browser, on the device you are using (its local storage). It is never sent to us or to anyone else. Each browser and each device has its own separate copy, and nothing is shared between them.

When you press End session & download or Download now, SmashTrack makes a season file and saves it to your device. That file is yours. SmashTrack does not keep a copy anywhere else.

What SmashTrack does not do

  • No accounts, sign-ups or passwords.
  • No analytics, advertising or tracking of any kind.
  • No cookies.
  • No requests to other websites. The fonts are built in, and the page is set up so the browser blocks connections to anywhere else.

Hosting

The site is hosted on GitHub Pages. Like any website host, GitHub can see ordinary visit information such as IP addresses when the page is first loaded, and handles it under its own privacy statement. SmashTrack does not receive or see any of it. After the first visit the app can run entirely offline.

Names and children

SmashTrack is made for school and club sessions, so the names you enter may be students. They stay on the device running the session and are never uploaded. Whoever runs the session is responsible for having permission to use people’s names, and for keeping season files somewhere safe.

Deleting your data

  • On the Session page, Erase everything and start over removes the saved session from that browser. Download a season file first if you want to keep it.
  • Clearing this site’s data in your browser settings removes it too.
  • Season files you downloaded are ordinary files on your device. Delete them like any other file.

Terms of use

SmashTrack is free to use, for school, club or personal sessions. It is provided as it is, with no warranty. Results are only as accurate as what is entered, and the person running a session decides how to use them.

The browser keeps your data on one device only, so download a season file to keep a backup. The code is shared under the MIT licence; see the LICENSE file in the repository.
